# CampusCue 🎓

**Your campus. Every opportunity.**

CampusCue is a college event and club discovery platform designed to bring campus activities together in one place. It helps students discover events and clubs while allowing organizers to submit event details for admin review and verification.

## ✨ Planned Features

- 📅 Discover college events in one place
- 🏫 Explore college clubs and their activities
- 🔍 Search and filter events by category and date
- 🖼️ Extract event details from posters using OCR
- ✏️ Review and edit extracted information manually
- 🔗 Submit official college and club source links
- 🤖 AI-assisted event verification
- 🛡️ Admin review and approval workflow
- 👥 Role-based access for students, organizers, and admins

## 🛠️ Tech Stack

- **Frontend:** React, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **API Integration:** Axios
- **OCR:** Tesseract.js
- **AI Assistance:** To be integrated

## 🚧 Project Status

CampusCue is currently in the planning and development stage. Features will be implemented incrementally, with a focus on learning, security, and building a reliable full-stack application.

## 🎯 Goal

To make college events easier to discover and event information more trustworthy through poster text extraction, official source links, and admin-controlled verification.
